# 烦恼弹弓

把让你烦的事变成靶子，然后用弹弓把它们一朵一朵打掉。

这是一个轻量的浏览器小游戏：天空里漂浮着写有烦恼的云朵，玩家按住弹弓、拖拽瞄准、松手发射石子。击中云朵后，云朵会炸开彩虹和星星；当屏幕上的所有云朵都被击落后，游戏会出现鼓励语，并引导用户记录此刻的想法，形成每日记录。

## 功能

- 拖拽弹弓发射石子，力度和角度会影响抛物线轨迹。
- 云朵在屏幕上半部分自由漂移。
- 默认烦恼云包括：工作焦虑、学习压力、金钱压力、孤独、年龄焦虑、情感困惑、迷茫。
- 支持自定义添加今天想打掉的烦恼。
- 击中云朵后有粒子爆炸、拟声词和连击反馈。
- 连续击中 3 朵云后，弹弓升级为火焰弹模式。
- 全部云朵击落后显示：

```text
精准度太棒了！让烦恼都烟消云散！
```

- 用户可以记录此刻的想法。
- 每日记录按日期由近及远排列，点击日期可查看当天击落的云朵和记录内容。
- 支持本地浏览器存储。
- 也提供一个简单 Node.js 后端，用于账户注册、登录和按账户保存每日记录。

## 直接打开本地版本

如果只想玩游戏，不需要账户同步，可以直接打开：

```text
index.html
```

这种方式下，每日记录会保存在当前浏览器的 `localStorage` 中。关闭浏览器后记录仍会保留，但换浏览器、清理浏览器数据或使用无痕模式时可能看不到原来的记录。

本地存储键名：

- `slingshot-worries-v1`：当前还没击落的云朵
- `slingshot-diary-v1`：每日记录
- `slingshot-session-v1`：账户登录状态

## 使用账户同步版本

账户功能需要启动本地 Node.js 服务，不能直接用 `file://` 打开。

### 环境要求

- Node.js 18 或更高版本

### 启动服务

在项目目录运行：

```bash
node server.js
```

然后访问：

```text
http://127.0.0.1:4173
```

Windows 用户也可以双击：

```text
start-server.bat
```

注意：命令窗口必须保持打开。关闭窗口后，服务会停止，账户功能也会无法连接。

## 账户与数据

账户数据保存在项目目录下：

```text
data/store.json
```

保存内容包括：

- 用户名
- 密码哈希和盐值
- 登录会话 token
- 该账户的每日记录

密码不会明文保存，后端使用 Node.js 原生 `crypto.pbkdf2Sync` 生成密码哈希。

## 项目结构

```text
.
├── index.html          # 页面结构
├── style.css           # 游戏 UI 和弹层样式
├── game.js             # Canvas 游戏逻辑、日记逻辑、账户前端逻辑
├── server.js           # Node.js 静态服务和账户 API
├── start-server.bat    # Windows 一键启动脚本
├── start-server.ps1    # PowerShell 启动脚本
└── data/               # 账户数据目录，运行后自动生成 store.json
```

## API

后端提供以下接口：

- `POST /api/register`：注册账户
- `POST /api/login`：登录账户
- `GET /api/me`：读取当前登录账户和日记
- `GET /api/diary`：读取每日记录
- `PUT /api/diary`：保存每日记录

需要登录的接口使用：

```http
Authorization: Bearer <token>
```

## 部署说明

当前项目默认适合本地运行。若部署到云服务器，需要将 `server.js` 的监听地址调整为公网可访问地址，或通过 Nginx 反向代理暴露服务。

本项目没有使用数据库，账户和每日记录都写入本地 JSON 文件。如果要做多人长期使用，建议后续换成 SQLite、PostgreSQL 或其他数据库。
